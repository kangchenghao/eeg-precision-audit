# 脑电空间滤波的逐行精度恢复

这段标准库 Python 程序用首轮实验保存的四项特征重算每种行组合。每次只替换同一个人、同一个试次、相同输入上的空间滤波权重精度。每行都独立对 22 通道做投影，再独立取对数功率。四个特征之间没有归一化，混合后的分数可以用原分类器直接计算。

## 运行

在 TTA 工作区根目录使用 Python 3.10 或更新版本。Windows 示例为

```powershell
py -3.13 portfolio/eeg-row-restoration/analyze_row_restoration.py
```

默认读取 `build/bci-fixedpoint-pilot-2026-11-15/private-run-02` 的九个模型、九份预测以及训练清单和结果，共 20 个文件。先把文件哈希与历史审计核对，再重建已记录的全部端点。可以指定 `--run` 使用另一个位置的同一份归档。对用原项目重新生成的试验，可显式传入 `--independent-run` 接受新的文件哈希，输出会注明本次输入是否与历史文件逐字节相同。实验来源与数据取得方式见 [原实验数据说明](../eeg-fixedpoint-audit/DATA_NOTICE.md)。

默认的聚合目录是 `output/bci-row-restoration-2026-11-18`，逐试次分数只保存在 `build/bci-row-restoration-2026-11-18/private`。可用 `--public` 和 `--private` 改目的地。私有模型、逐试次特征、标签、分数与记录仅在本机使用。

## 结果读法

- `subset-counts.csv` 的每一行对应一个固定方案在 1,296 个试次上的表现。`X16` 表示相同的 16 位输入，`Xfloat` 表示相同的浮点输入。`Wfp` 表示原浮点权重。低精度和目标精度写在方案名中。
- `mask` 是四行的二进制选择，最低位对应第 1 行。0 表示全部用起点精度，15 表示全部用终点精度。可直接读 `restored_rows` 确认哪些行得到恢复。
- `vs_fixed_input_Wfp` 统计与相同输入、四行均为浮点权重的判定分歧。`vs_full_float` 的参照同时使用原浮点输入与浮点权重。`repair` 和 `induce` 分别记从起点恢复精度后，消除和新增的同输入判定分歧。计算正确率时使用原提示标签；在本次平衡数据中，整批准确率等于逐人平衡准确率的平均。
- `aggregate.json` 保留每人每种配置的分歧和正确数。不同人的同一行号来自各自训练的滤波器。试次级「至少恢复几行」对每个试次查看全部组合，允许不同试次用不同行；该数字衡量解释能力。
- 每个行分数改变量等于冻结 LDA 系数乘以该行特征的改变量。对数功率可能随输入量化与权重量化非线性变化，本实验用同一输入的实际端点特征计算。四项相加是分类器分数的变化，跨越零分才会改变判定。总绝对改变量大于零时，抵消比例等于 1 减去「四项之和的绝对值 / 四项绝对值之和」。
- `both_endpoints_agree_but_intermediate_disagrees` 统计起点与终点均符合同输入参考，而某个中间组合出现分歧的试次。`restore_more_introduces_disagreement_edges` 遍历每个组合，将任一尚未恢复的行提高精度，记录这一步从一致变为分歧的次数。一个试次可以有多条这样的边。
- 同一分数分别由混合特征直接代入 LDA、以及从已存低精度分数累加行改变量计算。程序核对两者的数值容差和判定。所有分析均为已查看评估日 E 的事后诊断。

BNCI Horizon 2020 001-2014 / BCI Competition IV 2a 数据来自格拉茨技术大学。数据许可、文献和下载核验均列于原实验数据说明。本轮行组合的软件实现与核对由 Codex 完成，沿用前次 Claude 讨论形成的实验范围。
