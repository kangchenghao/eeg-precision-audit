# AI-assisted development

AI tools assisted with study planning, code, tests, experiment automation,
documentation and critical review. Their suggestions were checked against
original documentation, independent arithmetic references and actual runs.
Review text alone is not experimental evidence.

The project owner selected the research goal, supplied the hardware and schedule
constraints, required fair comparisons, and authorized this implementation.
This record does not claim that all source code was independently hand-written
by the owner or that the learning exercises have already been completed.

Private credentials, provider connection details and model-call logs are not
part of the public project. Original dataset ownership and licenses are separate
from original project code.
